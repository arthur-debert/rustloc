- Show the Comments column by default: without `--type`, count and diff tables now show code, tests, docs, comments, and total. Pass `--type code,tests,docs,total` for the previous columns. JSON, YAML, and XML output report the new selection in `line_types`.
- Group digits in count, diff, and commit tables by default (for example `12,345`, following the active locale). `--number-fmt` now takes a value: `--number-fmt=false`, or `number_fmt = false` in `rustloc.toml`, prints plain digits as before; a bare `--number-fmt` or `--number-fmt=true` keeps grouping on, and the flag overrides the config file.
