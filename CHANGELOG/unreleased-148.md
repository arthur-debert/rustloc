- Rustloc now parses Rust syntax instead of scanning characters itself. The old scanner could misread valid string and character literals, causing later `#[test]` functions to be reported as production code. In a 993-line Proiectio file, the corrected classification is 264 code / 510 tests instead of 877 code / 0 tests. Rustloc still does not treat a separate file as entirely tests merely because a parent module declares it under `#[cfg(test)]`.
