- `cargo install rustloc` works again without `--locked`. Ruff's dependency range allowed an incompatible `get-size2` release, so fresh installations failed even though workspace builds using `Cargo.lock` passed. Rustloc now constrains `get-size2` to the compatible release and verifies unlocked installations in CI. For Rustloc 0.22.0, use `cargo install --locked rustloc --version 0.22.0`.
