- `cargo install rustloc` builds again without `--locked`. Rustloc's Python parser, `ruff_python_ast`, keeps identifiers in a `compact_str 0.9::CompactString` and derives `get_size2::GetSize` for them while asking only for `get-size2 = "0.10.0"`; get-size2 0.10.2 moved its `compact_str` support to 0.10, so a fresh resolution picked 0.10.3, ended up with both `compact_str` versions in one graph, and the build stopped at "the trait bound `CompactString: GetSize` is not satisfied". A build from the checked-in lockfile never saw it, which is why the workspace and `cargo install --locked` stayed green. Rustloc now requires `get-size2 = "=0.10.1"`, the last release that agrees with ruff on `compact_str`, so every resolution lands on the compatible pair; counting and diffing behave exactly as before. `cargo install --locked rustloc --version 0.22.0` remains the way to install the already-published 0.22.0.
